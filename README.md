# Python Task 4 - REST API with Flask

## 📌 Project Overview

This project is part of the Python Developer Internship - Task 4.

The objective of this task is to build a REST API using Python and Flask to manage user data.

The API supports the following HTTP methods:

- GET
- POST
- PUT
- DELETE

User data is stored temporarily in an in-memory Python dictionary.

---

## 🛠️ Technologies Used

- Python
- Flask
- REST API
- JSON
- Postman / cURL
